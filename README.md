# MeetNova 🎥

**MeetNova** is a real-time video conferencing platform built with **React, Node.js, Socket.IO, and WebRTC**. It allows users to create and join meetings with real-time video and audio communication.

## ✨ Features

* 🔐 User authentication
* 🎥 Real-time video & audio calling
* 👥 Create and join meetings
* 🔗 Meeting rooms with unique IDs
* ⚡ Real-time communication using Socket.IO
* 🌐 Peer-to-peer communication using WebRTC
* 📱 Responsive UI

## 🛠️ Tech Stack

**Frontend**

* React.js
* Vite
* Tailwind CSS

**Backend**

* Node.js
* Express.js
* Socket.IO
* MongoDB
* Mongoose

**Real-Time**

* WebRTC
* Socket.IO

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/officialvikas455/MeetNova.git
cd MeetNova
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```

Create a `.env` file in the backend:

```env
PORT=5001
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret
```
